# Microsserviço de Agendamento de Tarefas

Microsserviço desenvolvido com Java 17 e Spring Boot, responsável pelo gerenciamento e agendamento de tarefas.

### Funcionalidades
- Cadastro e gerenciamento de tarefas
- Definição de datas e horários
- Consulta e atualização de tarefas
- Integração com o serviço de usuários
- Persistência de dados com MongoDB

### Tecnologias
Java 17 · Spring Boot · Spring Data MongoDB · MongoDB · Docker
